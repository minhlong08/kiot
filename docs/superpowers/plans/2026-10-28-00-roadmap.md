# PhuongDong POS — Roadmap

**Spec:** `docs/superpowers/specs/2026-10-28-phuongdong-pos-design.md` + `docs/requirements.md`

Each milestone gets its own detailed plan file `docs/superpowers/plans/2026-10-28-NN-<name>.md`, written immediately before that milestone starts so it can cite the real interfaces of what already exists. The owner chose to run all 10 without review stops; each milestone ends with tests green and a commit.

| # | Plan file | Delivers | Depends on |
|---|-----------|----------|------------|
| 1 | `01-foundation.md` | Monorepo, Prisma (SQLite), auth + sessions + forced password change, roles/permissions, branches, users, settings, document codes, audit log, admin shell (top bar, mega-menu nav, Bán hàng button), generic list kit (DataTable, FilterSidebar, ListToolbar, export), i18n, POS app stub at `/sale`, Playwright harness | — |
| 2 | `02-products-stock.md` | Product groups (tree), brands, locations, attributes, products (goods/service/combo, variants, units, images, warranty, branch availability), BranchStock + StockLedger + `stockService`, stock card, price books, stock take, internal use, write-off, **branch transfers**, Excel import/export, barcode labels | 1 |
| 3 | `03-purchasing.md` | Suppliers + groups, PartnerLedger (supplier side), supplier payments, **purchase orders**, goods receipts with weighted-average cost per branch, purchase returns, incoming invoices, service purchases | 2 |
| 4 | `04-customers-promotions.md` | Customers (+ VN admin data), groups with auto-assign, PartnerLedger (customer side), loyalty, promotions engine (pure functions), vouchers, messaging log + stub adapter | 1 |
| 5 | `05-pos-sales.md` | POS app (tabs, cart, search/scan, customer, price book, payment panel, VietQR, receipts, modes, IndexedDB offline queue, shifts), invoices, returns/exchange, customer orders with reservation | 2, 3, 4 |
| 6 | `06-cashbook-debts.md` | Cash funds, categories, vouchers, auto-entries from all documents (retrofit into M3/M5 services through `cashService`), debt screens | 3, 5 |
| 7 | `07-delivery-online-tax.md` | Delivery partners, waybills, delivery tracking + COD reconciliation, carrier adapter; sales channels + online inbox; `/shop` storefront; tax settings, e-invoices, tax declaration helper | 5 |
| 8 | `08-staff.md` | Employees, shifts, drag-and-drop schedule, timesheets, salary templates, payroll → cash book, commission tables, permissions matrix UI | 1, 6 |
| 9 | `09-dashboard-reports.md` | Dashboard widgets + activity feed + suspicious login card; all report groups with chart/table/print/Excel | all above |
| 10 | `10-polish.md` | Keyboard shortcuts, print template editor, label templates, responsive POS, backup/restore, reset demo, full seed (40 products, ~45 docs over 30 days), Docker + Postgres, README, full E2E scenario | all above |

Cross-cutting rule: any service that changes stock, debt, cash or points writes its ledger rows through the single service for that ledger, inside the caller's `tx`. No route touches ledger tables directly.
