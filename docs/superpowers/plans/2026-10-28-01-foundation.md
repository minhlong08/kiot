# Milestone 1 — Foundation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A running monorepo where an admin logs in, is forced to change the default password, sees the full app shell with every module in the nav, manages users/roles/branches/settings, and every change lands in an audit log — plus the reusable list kit every later module uses.

**Architecture:** Fastify API with Prisma (SQLite file `data/app.db`), cookie sessions stored in DB, permission keys checked by a route-level `requirePermission`. Admin is a Vite React SPA with TanStack Router (code-based routes) and Query; dev proxy `/api` → API. POS is a stub Vite app at base `/sale/`. Shared Zod schemas and formatters in `packages/shared`.

**Tech Stack:** Node 24, pnpm workspaces, TypeScript 5, Fastify 5, Prisma (latest stable), Zod, bcryptjs, exceljs, React 19, Vite, TanStack Router + Query, Tailwind CSS 4, Vitest, @testing-library/react, Playwright.

**Spec:** `docs/superpowers/specs/2026-10-28-phuongdong-pos-design.md`, `docs/requirements.md`

## Global Constraints

- App name lives only in `packages/shared/src/config.ts` as `APP_NAME = "PhuongDong POS"`.
- Default login `admin` / `admin123`, `mustChangePassword = true` on seed.
- Money: integer đồng; display `1,234,000` (comma thousands, no decimals). Dates `DD/MM/YYYY HH:mm` in `Asia/Ho_Chi_Minh`.
- Money columns are Prisma `Int`; every money input schema caps at `2_000_000_000` (Zod) with Vietnamese message "Giá trị quá lớn".
- Document codes: prefix + 6 digits (`HD000045`), auto, editable on create.
- Every create/update/delete writes an `AuditLog` row in the same transaction.
- Vietnamese UI default; all user-visible strings go through `t()` with `vi` and `en` dictionaries.
- Own palette: primary teal `#0f766e`, accent amber `#f59e0b`; no vendor blue, logo, or icons. Icons from `lucide-react`.
- SQLite has no enums: status/type fields are `String` validated by shared Zod enums.
- `pnpm install && pnpm dev` must work from a clean clone: migrate, seed if empty, start API (3000), admin (5173, opens browser), POS (5174, proxied at `/sale`).

## Review Focus

1. **Two documents created at the same moment get the same code** → `nextCode` must be atomic; test runs 20 parallel `nextCode('HD')` and expects 20 distinct codes (Task 3).
2. **Searching without diacritics** ("ao vest" should find "Áo vest", "đ" ↔ "d") → `normalizeVi()` in shared, used for every `searchText` column (Task 2).
3. **"Hôm nay" near midnight** computed in UTC instead of Vietnam time → `dateRangePreset('today', now)` test at `2026-10-28T17:30:00Z` returns 29/10 local day (Task 2).
4. **User with `mustChangePassword` calls other APIs directly** → every route except `/api/auth/*` returns 403 `PASSWORD_CHANGE_REQUIRED` (Task 4).
5. **Disabled user keeps an old session** → deactivating a user deletes their sessions; next request 401 (Task 5).
